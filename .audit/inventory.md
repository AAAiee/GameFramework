## Binary facts

- `Regression` (Tests/Build-Regression.lua): ConsoleApp, C++20, links `Engine`, compiles `Tests/src/**.h|.cpp` plus production `Editor/src/EditorLayer.cpp`, `Editor/src/Panels/SceneHierachyPanel.cpp`, `Editor/src/Utilities/FontsManager/FontManager.cpp`; copies editor assets and `imgui.ini` beside the exe. 18 selectors in the usage string (Regression.cpp:96-97).
- `UnitTests` (Tests/Build-UnitTests.lua): ConsoleApp, C++20, static CRT. Compiles exactly three TUs/files: `Tests/unit/UnitTests.cpp` (doctest `DOCTEST_CONFIG_IMPLEMENT_WITH_MAIN`, vendored doctest v2.4.12, one `TEST_CASE("camera-inverse")` wrapping `CHECK_NOTHROW(Rubber::checkCameraInverse())`), `Tests/src/CameraInverseCheck.cpp` (+ its `.h`, the shared F02 oracle), and the `Vendor/doctest/doctest.h` header. It does **not** link Engine, OpenGL, windowing or editor code; it reaches only Camera/GLM headers through `../Engine/Source` and `../Engine/RBVendor/glm`. `DOCTEST_CONFIG_DISABLE` is rejected by `#error`.
- `main()` wiring (Regression.cpp:95-191): every selector, including headless ones, runs inside `RegressionDesktop` (a process-private Windows desktop created before any check; failure to isolate throws). Order: `camera-inverse`, `layer-partition`, `Logger::Init()`, `typed-events`, `event-names`, `font-atlas` (all before `glfwInit`), then `glfwInit()` + hidden `Application` + GL 4.5 context, then `gl-buffers`, `gl-boundaries`, `atlas-placeholders`, `scene-hooks`, `renderer-batches`, `entity-tags`(+16 marker), `editor-issue-12`, `editor-issue-15`, `viewport-pixels`(+17 marker), `minimize-restore`(+18 marker). No arguments run everything in that order; an unknown selector exits 2.
- The five `issue-*.ps1` scripts are launcher/guard wrappers: they locate `Regression.exe`, run one selector with a bounded timeout, capture `issue-N.stdout/stderr.log` beside the binary, require exit 0 plus the exact `PASS:` marker, and kill only the process they started. `unit-tests.ps1` is the issue #29 acceptance harness for the headless target.
